### Key Technical Insights

1. **SwiftUI Shadow Behavior**: `.shadow()` modifier applies to the rectangular bounding box, not to clipped shapes. Solution: Use `RoundedRectangle.shadow()` in `.background()`

2. **NSVisualEffectView Compatibility**: Cannot use `.drawingGroup()` with views containing `NSVisualEffectView` - causes complete rendering failure

3. **NSPanel Shadow**: `hasShadow = true` on borderless NSPanel creates ugly rectangular system shadow. Must use custom SwiftUI shadow layer.

4. **Layer Separation Pattern**:
```
[Shadow/Glow Layer] (background, no hit testing)
    └── [Card Content Layer] (clipped RoundedRectangle)
        └── [Overlay Border Layer]
            └── [Padding Layer] (for shadow space)
```
