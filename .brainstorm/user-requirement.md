# User Requirement

## 1. 截图交互优化 (UX Polish)
- **初始状态**: **保留**全屏变暗的遮罩（Overlay），但被选中的区域是完全透明的（高亮）。
- **视觉风格**:
  - **去框线**: 移除选区明显的边框线，仅通过明暗对比（Mask）来体现选区。
  - **光标**: 替换系统光标，使用一个**自定义的小十字准星**。
  - **放大镜**: 在光标右下角（或跟随位置）添加一个**放大镜 (Loupe)**，显示像素级细节。
- **完成状态**: 截图成功后，形成一个“包裹感”的视觉反馈。

## 2. 窗口吸附/监控模式 (Window Snapping/Monitoring)
- **交互**: 鼠标移动时，自动识别并高亮当前鼠标下的窗口区域（选区吸附）。
- **合规性**: 确保使用的技术（如 ScreenCaptureKit）符合 App Store 上架规范，不使用非官方 API。
