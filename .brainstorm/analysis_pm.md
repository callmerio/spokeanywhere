# Product Manager Analysis - Raycast 风格查词功能

## Vision
打造一个**快速、沉浸式**的英语学习辅助工具，让用户在任何场景下都能一键查词、管理生词，形成"**遇到就查，查了就记**"的学习闭环。

## User Value

### 核心用户场景
1. **主动学习** - 用户想查一个词的详细用法
2. **巩固记忆** - 快速标记/复习生词
3. **词形探索** - 了解一个词的各种变形（ripe → ripeness, ripen, ripened）

### 与现有功能的差异化
| 功能 | 现有划词查词 | 新查词面板 |
|------|-------------|-----------|
| 触发方式 | 划选文本 | 主动输入 |
| 词形变化 | ❌ | ✅ 词族列表 |
| 详情深度 | 简单释义 | 同义词/反义词/例句 |
| 生词管理 | 右键菜单 | Tab 一键标记 |

### 用户价值总结
- **效率提升** - 键盘流操作，无需鼠标
- **学习深度** - 看到词族关系，理解词根词缀
- **记忆增强** - 查词 + 标记生词一体化

## Requirements

### Must Have (P0)
1. 输入框 + 搜索结果列表
2. 键盘导航（↑↓ 选择，Enter 详情，Tab 标记生词）
3. 生词橙色高亮
4. 词典释义展示（复用 DictionaryAPIService）

### Should Have (P1)
1. 词形变化列表（ripe → ripen, ripened, ripeness）
2. 详情视图（同义词、反义词、例句）
3. ESC 关闭 / 返回上一级

### Nice to Have (P2)
1. 搜索历史
2. 发音播放（TTS）
3. Open in Dictionary.app

## Business Case

### ROI 分析
- **开发成本**: 中等（~3-5天）
  - 复用现有 DictionaryAPIService + VocabularyService
  - 主要工作是 UI 层
- **用户价值**: 高
  - 填补"主动查词"场景空白
  - 提升产品作为学习工具的定位

### 风险
- **依赖后端 API** - 词典 API 不可用时功能受限
- **词形变化数据** - 需要额外数据源或算法
