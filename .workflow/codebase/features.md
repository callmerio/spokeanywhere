# Features

## Overview

SpokenAnyWhere provides native macOS workflows for voice-to-text, AI-assisted text processing, real-time captions, screenshot/OCR capture, selection-based actions, message panels, pinned desktop text, dictionary/vocabulary support, TTS, and settings-driven personalization.

## User Journey Patterns

- Hotkey-first feature access for recording, Quick Ask, screenshot, message panel, clipboard pipeline, and live captions.
- Floating UI surfaces instead of document-style windows.
- Context-enriched AI using selected text, OCR, screenshots, clipboard, live captions, app context, and voice transcription.
- Settings-backed personalization through `AppSettings`, `LLMSettings`, workflow actions, and toolbar actions.

## Extension Guidance

- Add new AI actions to `WorkflowAction` or `SelectionActionService` rather than creating ad-hoc flows.
- Use `ServiceContainer` as the primary feature-to-service map.
- Preserve existing hotkey and floating-panel patterns for new user-facing workflows.
