# SpokenAnyWhere v0.1.0

- Date: 2026-04-20
- Release Type: Stable

## Summary

`v0.1.0` 是 SpokenAnyWhere 从“持续开发”进入“正式版本化”阶段的第一版。这个版本重点不是新开一条大产品线，而是把最近一轮高频使用的贴屏文字 / overlay 体验打磨到更稳定、更自然，同时把后续发版所需的 release discipline 建立起来。

## New

- **正式 release discipline 起步**
  - 从这一版开始采用 `v0.X.Y` 的 milestone-driven 版本语义
  - 建立 `CHANGELOG + docs/releases + GitHub private release` 的分层方法
- **Pinned Text 缩放体验升级**
  - 贴屏文字支持更连贯的 preview zoom、commit 连续性和更自然的 follow-through
- **更低的最小缩放下限**
  - 允许贴屏文字缩到更小，适合“只留一点提示感”的使用方式

## Improvements

- **Pinned Text / Screenshot overlay 交互开始统一**
  - 横向滑动统一调透明度
  - 最低透明度统一到更轻的存在感
  - 右键菜单骨架与 glow token 开始对齐
- **边缘视觉统一**
  - screenshot 与文字贴图的黑圈厚度和边缘 glow path 收敛到同一套基准
- **后续发版基础设施开始正规化**
  - release notes、版本号来源、发布入口开始收口

## Fixes

- 修复贴屏文字缩放时文字与背景卡片割裂的问题
- 修复缩小时 hover 丢失导致的回弹问题
- 修复 scrollable content 下的非等比缩放问题
- 修复贴屏文字左上角拖拽缩放越界时可能直接消失的问题

## Known Issues

- 当前 release 链路已经正规化到“版本号、notes、workflow 对齐”，但还没有接完整的 Developer ID + notarization 正式分发链
- 一些 overlay 视觉细节仍可能继续微调，但不会改变本版的整体交互语义

## Upgrade Notes

- 本版本继续使用 `com.spokeanywhere`
- 如果你此前使用的是旧身份 `app.spokenly`，项目内部已有迁移兼容逻辑，但发版脚本现在也会统一对齐到 `com.spokeanywhere`
- 后续日常开发中的变更会先进入 `CHANGELOG.md` 顶部的 `Unreleased`
